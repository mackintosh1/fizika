Исследование

Цель — отделить случайные сгущения от устойчивой закономерности и установить, как границы, направленность шагов и ловушки изменяют перенос.

Гипотеза

Без предпочтительного направления среднее смещение близко к нулю, а средний квадрат смещения в свободной среде растёт линейно. Стенки ограничивают разброс. Асимметрия вероятностей создаёт дрейф; поглощающие ячейки уменьшают долю частиц, достигших приёмника.

Проверяются четыре режима на одной математической основе. Основные серии содержат по 50 повторов; ансамбль в каждом повторе — 100 независимых частиц.

⟨r²(t)⟩ = 4Dt = 1,5t
D = ⟨|δr|²⟩ / 4 = 0,375Для восьми равновероятных соседей при a = 1 и Δt = 1.
Формула действует в свободной среде; в ограниченной области — до заметного влияния стенок. Все величины заданы в ячейках и тактах.
Модель и отражение на границах

Состояние частицы — пара индексов (i, j), где i, j ∈ {0, …, 99}. Физические координаты центров ячеек: x = i + ½, y = j + ½. Стенки расположены при x, y = 0 и 100. На каждом такте независимо выбирается один из восьми векторов. Для оси отражается нормальная компонента смещения; касательная сохраняется. В индексах выход −1 переходит в 0, а 100 — в 99. Это зеркальное отражение относительно границ ячеек.

Например, шаг (−1, +1) из (0, j) даёт (0, j + 1): частица доходит до левой стенки и возвращается на прежнюю координату x. Угол отражается по обеим координатам. Произвольный целый индекс q сворачивается с периодом 200: при 0 ≤ u < 100 результат u, иначе 199 − u, где u = q mod 200 с неотрицательным остатком.

Для симметричных шагов матрица переходов симметрична. Равномерное распределение по 10 000 ячейкам стационарно. Частицы могут занимать одну ячейку и проходить друг через друга: взаимодействие и исключённый объём отсутствуют.

Дрейф и корректное измерение диффузии

Направленность задаётся вероятностями pₖ = exp(βδxₖ) / Z. При запрете шагов влево их веса обнуляются, остальные нормируются. Параметр β безразмерный; связь с напряжением или температурой здесь не калибруется. При a = 1: vₓ = 6 sinh β / (2 + 6 cosh β), vᵧ = 0.

Если μ = ⟨δr⟩, C = Cov(δr), то для независимых шагов в свободной среде ⟨|r(t) − r(0)|²⟩ = t tr C + t²|μ|². Дрейф даёт квадратичный вклад. Поэтому D̄ = tr C / 4 оценивается по центральной дисперсии, а не по полному квадрату смещения. При анизотропии это среднее (Dₓₓ + Dᵧᵧ)/2, а не полный тензор диффузии.

Для ансамбля из N = 100 используется несмещённая оценка V = Σ|Δrᵢ − Δr̄|² / (N − 1). Оценка D̄ = V / (4t). При запрете трёх направлений влево vₓ = 3/5, Dₓₓ = 0,12 и Dᵧᵧ = 0,40.

Протокол вычислений и неопределённость

Свободная среда: 50 ансамблей по 100 частиц, 200 тактов, β ∈ {0; 0,35} и отдельный режим запрета движения влево. Область со стенками: 50 ансамблей по 100 частиц, 5000 тактов, старт из ячейки (49, 49). Из каждого ансамбля дополнительно сохранена траектория первой частицы; для рисунка берётся каждая десятая точка.

Барьер: 50 независимых реализаций среды для каждой ρ ∈ {0; 0,08; 0,16; 0,24; 0,32; 0,40}, в каждой — 100 частиц и 1000 тактов. Старт i = 10, j равномерно от 0 до 99; β = 0,35. Ловушки независимо размещаются в столбцах i = 45, …, 54. Ячейки i = 99 — приёмник. И попадание в ловушку, и достижение приёмника необратимы.

Генератор Mulberry32, отдельный фиксированный seed для каждого повтора. 95%-е интервалы: среднее по 50 независимым сериям ± 2,0096·s/√50. При исследовании барьера единица повторения — вся реализация среды, что учитывает общий ландшафт для 100 частиц. Вырожденный интервал при отсутствии событий не означает нулевую вероятность события.

Перенос и захват

Даже редкие ловушки заметно подавляют прохождение.

Частица многократно пробует разные пути через слой шириной 10 ячеек. Контакт с любой ловушкой завершает её движение. В опыте измеряется доля, которая достигает правого приёмника за 1000 тактов.

При ρ = 8 % до приёмника дошли 13,50 % частиц; при ρ = 16 % — 1,94 %. В контроле без ловушек достигли все 5000 частиц.

Поглощение — правило классической стохастической модели. Здесь не рассчитываются квантовое туннелирование, энергия электрона, ток в амперах или реальные свойства материала.

Выводы

Диффузия

Симметрия шагов обнуляет средний дрейф, но оставляет линейный рост дисперсии. Непредсказуемость отдельного пути совместима с точным законом для ансамбля.

Направленный перенос

Асимметрия вероятностей создаёт ненулевую скорость. Полный квадрат смещения содержит вклад дрейфа; для оценки диффузии нужен центральный момент.

Захват

Поглощающие ячейки отбирают траектории. Долю прохождения определяют плотность и конфигурация ловушек, время наблюдения и направление движения.
